# Netflix Content Trends Analysis Project

## Overview
This project explores the Netflix dataset containing Movies and TV Shows produced between 2008 and 2021. Our objective is to reveal strategic patterns in content distribution, genre popularity, and global catalog expansion. These insights are intended to guide Netflix's business decisions on content acquisition and production.

## Dataset
- Source: [Netflix dataset]
- Records: 7,789 entries
- Columns: Title, Director, Cast, Country, Date Added, Release Year, Rating, Duration, Genre, Type (Movie/TV Show)

## Problem Statement
Netflix faces growing competition from other streaming platforms. To remain competitive, it must adapt its catalog and content strategy based on real viewer preferences and global market trends.

## Objectives
- Examine the ratio and trends of Movies vs. TV Shows
- Identify top genres and their changes in popularity
- Analyze country-wise contributions to Netflix's library

## Technologies Used
- Python
- pandas, numpy for data cleaning and exploration
- seaborn, matplotlib for visualization
- scikit-learn (or similar) for linear regression modeling

## Key Insights
- Clear visualization of content trends and shifts
- Strategic recommendations for catalog management
- Actionable conclusions for future content decisions
